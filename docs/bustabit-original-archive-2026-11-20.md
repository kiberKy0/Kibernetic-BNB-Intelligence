## Codici originali
Sei file sorgente utente recuperati da ChatGPT Library. Questo repository è pubblico: NON incorpora né pubblica il loro codice eseguibile. Il manifest /bustabit-archive-data.js contiene solamente nome originale, dimensione, hash SHA-256 e stato dell'audit.

L'utente importa i file originali nella pagina. La pagina calcola SHA-256 dell'ArrayBuffer, accetta solo hash di versioni archiviate e conserva i byte invariati in IndexedDB del browser; vista testo in sola lettura, esportazione .js originale per download. Non chiama eval, engine.bet o fetch. Lo storage è locale al browser/dispositivo e può essere cancellato dalle impostazioni del browser. Un test locale passato NON è una prova di corretto funzionamento LIVE.
